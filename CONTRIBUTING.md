# Contributing

Den här mallen är tänkt att vara enkel att kopiera, ändra och använda i nya projekt.

## Arbetsflöde

1. Skapa eller välj en tydlig uppgift i `TODO.md`.
2. Gör små, sammanhängande ändringar.
3. Uppdatera dokumentation när strukturen eller arbetssättet ändras.
4. Kontrollera att inga hemligheter, lokala data eller stora loggar följer med.
5. Summera ändringen i `CHANGELOG.md` vid behov.

## Commit-stil

Använd korta, aktiva commit-meddelanden, till exempel:

- `Add Codex workflow guide`
- `Update project structure documentation`
- `Fix ignore rules for logs`

## Pull request-checklista

- [ ] Ändringen är kopplad till en tydlig uppgift eller förbättring.
- [ ] Dokumentation är uppdaterad där det behövs.
- [ ] Inga hemligheter eller lokala filer är inkluderade.
- [ ] Relevanta kontroller är körda, om projektet har sådana.
