# Prompt: Skapa dokumentation

Använd när Codex ska skapa eller förbättra projektdokumentation.

```text
Läs AGENTS.md och befintlig dokumentation först.

Dokumentera:
[Beskriv ämnet]

Målgrupp:
[Utvecklare, projektledare, verksamhet, drift, annan]

Krav:
- Skriv på svenska om inget annat anges.
- Var konkret och praktisk.
- Använd rubriker, tabeller och checklistor där det hjälper.
- Lägg dokumentet i rätt mapp enligt README.md.
- Uppdatera index eller README om dokumentet bör vara lätt att hitta.
```
