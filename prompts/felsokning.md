# Prompt: Felsökning

Använd när Codex ska undersöka ett fel, loggar eller oväntat beteende.

```text
Läs AGENTS.md först.

Problem:
[Beskriv felet]

Symptom:
- [Felmeddelande]
- [När uppstår det]
- [Vad förväntades]

Tillgänglig kontext:
- Relevanta filer/mappar: [ange om känt]
- Loggar: [ange var de finns]
- Senaste ändringar: [ange om känt]

Arbeta så här:
- Samla först fakta från filer, loggar och konfiguration.
- Identifiera trolig rotorsak.
- Gör minimal fix om det är säkert.
- Kör relevanta kontroller.
- Sammanfatta orsak, fix och kvarstående risk.
```
